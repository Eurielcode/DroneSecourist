# Décisions techniques (ADR)

d'architecture, de modèle, de format de données, etc.), au format « contexte / décision /
conséquences ». Un fichier par décision, nommé `AAAA-MM-JJ-sujet.md`.

Statut : à faire — aucune décision consignée pour l'instant (dépôt en cours de mise en place).
